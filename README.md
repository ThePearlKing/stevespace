Welcome to the stevespace.

---

Steve's Space Program is a Forge mod for Minecraft 1.21.1. Earth is a round planet you can walk all the way around. Build a rocket from blocks, fly it to orbit, and land on the Moon, Mars, Jupiter's moons, Pluto and the rest of the solar system. The planets and moons sit where they really are in the sky, and each one has its own ground, blocks and dangers.

## Building

```
./gradlew build
```

The jar ends up in `build/libs`. To play from source, run `./gradlew runClient`.
